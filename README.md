# BoxReel downloads

BoxReel turns your own game film into highlight videos, player reels, teaching cuts and stat sheets.
A [GrebStar Ventures](https://grebstar.com/boxreel/) product. This repository holds the installers only.

**Free beta, version 0.3.1.** 10 free videos per computer. Support: boxreelsupport@gmail.com (or the Support button in the app).

| Computer | Download |
| --- | --- |
| Windows 10 or 11 (64-bit) | [BoxReel-Setup.exe](https://github.com/grebstar/boxreel-releases/raw/main/BoxReel-Setup.exe) |
| Mac with an Apple chip (M1 or newer) | [BoxReel-Mac.dmg](https://github.com/grebstar/boxreel-releases/raw/main/BoxReel-Mac.dmg) |

Install steps, what the app sends, and how the free videos work: https://grebstar.com/boxreel/#download

`SHA256SUMS.txt` lists each file's checksum. `latest.json` is the version number the app checks for updates.

The installers include FFmpeg (GNU GPL) and the Poppins font (SIL Open Font License); their licenses
are inside the app's `LICENSES` folder.
